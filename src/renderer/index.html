Очередь

Пока пусто. Добавьте видео — перевод начнётся сразу.

Что сохранить

Оригинал + перевод, как в видео, — для плееров, которые подключают внешнюю дорожку. Не копирует само видео.

Куда

Рядом с исходным видео

Для новых видео

Голоса, похожие на оригинальных говорящих. Работают только с английского.

У каждого видео в очереди — свои голос и язык, их можно поменять в карточке.

Звук

Тихое видео — тише перевод, громкое — громче. Ползунок «Громкость перевода» действует поверх.

Яндекс Диск

Через Диск видео передаётся переводчику. Загружается только звук (картинка заменяется чёрным кадром). Копия хранится закрытой, пока видео в списке, и удаляется при «Убрать из списка» или выходе. Диск ограничивает скорость загрузки — около 2–3 минут на 20 минут видео.
